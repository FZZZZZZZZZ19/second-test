# V1.0 默认配置构建

日期：2026-10-30。该目录是可核查的构建快照，不是上板验证报告。

- WCH GCC 8.2，`rv32imafcxw / ilp32f`，104 个 C/汇编输入。
- Flash 内容 53380 字节，链接上限248KiB。
- data 296字节，bss及预留栈合计27160字节，合计27456字节；RAM32KiB，预留栈2KiB。静态链接尺寸不代表已经测出运行栈峰值。
- 新应用模块严格警告检查通过；逐飞原库有7条既存警告，完整位置见 `build-report.json`。
- 主机测试：默认配置5组/138406断言；测试用路线配置5组/138410断言。很多断言用于遍历16位计数器回绕，不应把断言数量当作硬件覆盖率。

`second-test-v1.0.elf` 可供调试，HEX/BIN 供适配的 WCH 下载工具使用。BIN 不携带地址，下载映射请按所用工具的 CH32V307 配置核对；HEX/ELF 保留链接地址。此工程未执行烧录。

**默认实测参数为零，固件保持静态调试并禁止准备/发车。** 填完实测参数与赛道配置后，运行 `tools/build.py` 生成自己的新固件。不要把本目录文件当作已经适配实车的比赛成品。

`build-report.json` 含输入文件哈希和产物哈希；`test-report.json` 含主机编译器与测试结果。图像、PI和状态机的电脑测试不能替代电机方向、相机完整帧和赛道实测。
