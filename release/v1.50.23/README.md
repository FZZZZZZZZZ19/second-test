# V1.50.23 车体电机左右归属修正

烧录second-test-v1.50.23.hex，主菜单显示V1.50.23。

用户观察左轮静止、右轮转动时，PWM显示左25%右0%，测速I1=0、I3约3.3m/s，手转左轮只影响I1。由此确定编码器左右正确，电机输出归属应交换。车体左输出改为TIM1 CH4/PE14，PH为PE13；车体右输出改为TIM1 CH1/PE9，PH为PE11。前进PH两侧0，编码器左TIM2、右TIM4，符号左-1、右+1。

电机板级函数提取到User/board/board_motor.c，便于主机执行实际的初始化、PWM和PH输出函数。新增测试按用户观测的物理输出归属记录两侧电机占空比：旧映射在左25%右0%的断言失败，修正后通过。另验证单侧输出、PH、停车和实际编码器采样符号。测试替代底层GPIO/PWM外设，实物映射仍需烧录后确认。

九组主机测试及WCH目标构建通过，Flash86340字节、RAM54192字节。本版尚未上板。参数格式沿用11。VOFA速度范围5m/s和占空比上限默认25%继续生效。
