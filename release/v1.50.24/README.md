# V1.50.24 预览刷新优化

烧录second-test-v1.50.24.hex，主菜单显示V1.50.24。旧版image/start页面每200ms刷新一次，软件限制最多5FPS。本版收到新帧即刷新。

对比用户Project原工程，原工程每个finish_flag到来后整图设置一次LCD窗口；此前本工程逐行设置120次窗口。本版改为一次设置(0,16)～(127,135)，按原图188列的行距取中间128列，连续发送灰度转换后的RGB565。保留128×120预览、188×120视觉输入和原相机50FPS配置，不增加显示整图缓冲。

当前工程还进行视觉处理与稳定帧复制，预览耗时也占主循环时间。实际刷新FPS及控制运行时序需上板测量，软件消除5FPS限制并不代表实测50FPS。

九组主机测试通过，旧版在间隔33ms的新帧刷新断言失败，修正版通过。显示测试逐像素核对188/128两种行距输入的RGB565输出，并验证整图只有一次窗口设置。WCH目标构建通过，Flash86284字节、RAM54192字节。本版尚未上板。
