# V1.50.15 视觉输入统一128×120

固件：second-test-v1.50.15.hex。视觉和屏幕预览使用同一张128×120灰度图，原点为图像内部(0,0)。底层188×120连续采集保持不变，在camera_frame.c只裁一次中间列30～157。直接使用用户原始八参，不使用V1.50.14的换算矩阵，投影公式不改。

Flash升级schema6。旧schema2/4/5加载时，中心坐标减30并限幅、超宽像素阈值截为128，八参导入用户本次原始标定；硬件尺寸、控制增益等保留。迁移先在RAM生效，停车后para → save to flash保存一次。之后schema6中的菜单修改继续保留。不需要全片擦除。详见[标定记录](../../docs/2026-11-19相机标定记录.md)。

八组主机测试通过，包含裁切边界、显示不重复裁切、Flash迁移及后续编辑保持。WCH GCC目标构建通过，Flash86812B、RAM46092B。构建仍有7条底层库已有警告（详见build-report.json）。本版未烧录、未上板，未测复制中断耗时、帧率和实车投影误差。队友完整视觉算法尚未提供，本版对齐输入接口，电控、motion_plan、速度PI、元素状态机和安全/超时逻辑未改。

build-report.json中的产物原名second-test-v1.50.*；本目录只改名，字节及SHA256不变。test-report.json为本版主机验证结果，calibration.json记录图像接口和原始八参。
