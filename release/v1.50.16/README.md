# V1.50.16 整帧视觉与显示预览

手动烧录 [second-test-v1.50.16.hex](second-test-v1.50.16.hex)。视觉和标定使用120行×188列整图，屏幕显示中间128列。原始八参作用于整帧像素。

升级后停车执行一次 `para → save to flash` 可保存迁移后的参数。旧格式6的中心列加30，旧格式2/4/5保留中心列。升级时采用用户确认的八个原始系数，车辆参数和控制增益继续使用已保存的值。详见[标定记录](../../docs/2026-11-19相机标定记录.md)。

八组主机测试和WCH目标构建通过，Flash占用86500字节，RAM占用54192字节。本版未烧录，整帧运行时序和实车投影误差尚待上板测量。
