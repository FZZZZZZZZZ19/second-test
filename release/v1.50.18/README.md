# V1.50.18 VOFA速度闭环与参数保存

手动烧录second-test-v1.50.18.hex。Flash参数继续使用schema8。

VOFA target保存检查停车模式、零PWM以及反馈速度绝对值小于0.01m/s。允许停车计数抖动，移除额外500ms等待。VOFA只请求速度闭环，检查参数合法、反馈有效和目标大于0。调试入口用实际参数和反馈判断可用性。比赛start继续执行完整标定检查。

在control → VOFA target m/s输入目标并SAVE，然后进入vofa。I0/I1/I2/I3依次为左斜坡目标、左实测速、右斜坡目标、右实测速。JustFloat、UART3、115200、8N1，每20ms发送20字节。PWM由原速度PI计算。run 30仍为单独固定30%开环命令。

八组主机测试通过，包含停车计数抖动时保存0.2m/s并读回、VOFA条件不足保持停止以及速度闭环请求。WCH目标构建通过，Flash86132字节、RAM54184字节。本版尚未上板验证。
