# V1.3 米制路径控制

本次将方向控制替换为曲率前馈与横向偏差 PD。没有算法切换开关。motion_plan、轮速 PI、元素状态机、运行状态机和安全控制文件保持不变。

## 接口与符号

VisionOutput 只在末尾追加 lateral_m、forward_m、curvature。横向右正，前向正，单位米；曲率右弯正，单位 1/m。保留的 direction_rad、distance_px 字段置零，不计算也不参与控制。其他时间戳、会话、有效性、停止传播机制不变。

```text
v = min(speed_cap_mps, speed_limit_mps)
omega = -v*curvature - (lateral_kp*lateral_m + lateral_kd*filtered_derivative)
```

omega 左转正，右偏或右弯产生负值。v 是当前帧建议速度限幅后的值，不是反馈速度，也不是 motion_plan 加减速之后的速度；本版不改变规划调用链。低速过渡时的曲率跟踪需上板验证。

D 使用新帧 capture_ms 的差分。首次、reset_derivative、间隔小于5ms或大于200ms清零，其余按 dt/(lateral_tau_s+dt) 一阶滤波。重复帧、错会话、无效值、非正 forward_m、负速度拒绝，invalid 仍传递 stop_requested。下游原有超时、限幅、停车机制保持原样。

## 如何标定

在最终安装角度、镜头和188×120图像尺寸下，采集地面已知点的像素坐标与车体坐标。以车辆用于运动学计算的参考点为原点，右为x、前为z；至少四个非共线点拟合单应矩阵，并用额外测量点验证。外参改变必须重标定。

```text
w = h6*u + h7*v + 1
x = (h0*u + h1*v + h2)/w
z = (h3*u + h4*v + h5)/w
```

将八个实测系数填入 vehicle_calibration.h 的 CAL_GROUND_H0..7。全部默认0，矩阵缺失/奇异时保持 invalid，不用近远行距离或白线宽度猜换算系数。不对整帧图像做逆透视，只投影选中路径的三个点。

取所选 path_index 的最近、中间、最远有效采样行，要求至少三行；投影到地面后前向距离必须严格递增且为正。最近点的 x/z 分别作为 lateral_m/forward_m。三点曲率为2倍有向叉积除以三条边长乘积，符号按“前向、右向”坐标顺序计算。直线为零，右弯正；点重合或数值异常无效。lateral_m 是最近有效前视点的偏差，并非车体原点处的垂直投影距离；可见近行变化会影响 D。

该估计是当前临时视觉适配器。只依赖状态机选出的路径行，不再使用出口/折点平均角；直角、急弯、遮挡与非单值曲线需实测。队友算法可直接输出相同米制接口。

## 调参和参数存储

control_tuning.h：lateral_kp 单位 rad/(s·m)，lateral_kd 单位 rad/m；默认均0，须实测调参。lateral_tau_s 默认0.05秒。先确认标定、正负号和轮速闭环，再低速验证前馈，随后逐步增加横向 P、D。示例数值仅存在测试夹具与算例中。

Flash 参数记录升级为 schema=2，旧记录即使 CRC 正确也拒绝加载；不能把旧增益解释成米制增益。保留原Flash存取安全流程，新系数与增益通过现有记录序列化。重新填入实测值、验证后再保存。
