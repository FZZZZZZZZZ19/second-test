# 相机地面标定 · V1.50.16

摄像头与队友视觉接口使用 `image[120][188]`，即120行、188列的灰度图。列号 `u=0..187`，行号 `v=0..119`，视觉直接用整帧坐标和原始八参计算地面位置。屏幕宽128像素，预览显示原图第30～157列。

同一个像素在三个位置的写法可以用画面中心附近的一点核对。原图数组的 `image[60][94]` 送给投影函数的是 `(u,v)=(94,60)`，画在液晶屏的 `(64,76)`。如果从屏幕读点，原图列号等于屏幕列号加30，原图行号等于屏幕行号减16。视觉算法拿到的已经是原图坐标，可直接投影。

## 用户给出的八个整帧标定系数

| 项目 | 源码/菜单值 |
|---|---|
| ground_h0 | `0.0045366634` |
| ground_h1 | `-0.000223055189` |
| ground_h2 | `-0.439942106` |
| ground_h3 | `-0.000210106974` |
| ground_h4 | `-0.0030013693` |
| ground_h5 | `0.561728764` |
| ground_h6 | `0.000546354536` |
| ground_h7 | `0.0137539169` |

```text
w         = h6*u + h7*v + 1
right_m   = (h0*u + h1*v + h2) / w
forward_m = (h3*u + h4*v + h5) / w
```

输出以米为单位，右和前为正。参数菜单路径为 `para → vision → camera calib`。

## 从之前的固件升级

V1.50.16 写入 Flash 参数格式7。加载格式6时，旧预览中心加30，例如63.5变为93.5。格式2、4、5的中心已经是整帧坐标。升级这四种旧格式时，八个相机系数统一采用本次确认的原值，保留其余已有车辆参数和增益。停车后执行一次 `para → save to flash` 即可保存。以后在格式7下编辑的标定会按保存值加载。

V1.50.14发布的矩阵包含额外的30列补偿。使用本页列出的八个原始系数。V1.50.15中的八个默认数值正确，当时视觉却只接收预览范围。本版将整帧交给视觉，再将画面中央部分送给显示驱动。
