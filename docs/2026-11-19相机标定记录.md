# 2026-11-19 相机地面投影标定（V1.50.15）

## 图像坐标与队友一致

用户确认：队友视觉算法输入128×120，标定也使用画面内部左上角(0,0)。因此当前视觉和屏幕预览必须共用这张图，而不是让视觉处理整张188图。

底层MT9V03X保持已正常工作的188×120连续采集；camera_frame.c在帧完成时取原图列30～157，复制为128×120稳定快照。FrameView的width=128、height=120、stride=128，视觉和显示共用同一快照。LCD把它画在y=16～135，标题偏移不属于图像坐标。显示不会再裁第二次。

V1.50.14把矩阵换算到188原图的做法已撤销；该版本换算值不适用于现在的128图。队友完整算法尚未提供，本版先统一其输入接口。

## 公式不用改变

```text
u = 0..127，v = 0..119（图像内部像素）
w = h6*u + h7*v + 1
right_m   = (h0*u + h1*v + h2) / w
forward_m = (h3*u + h4*v + h5) / w
```

右向为正、前向为正，输出单位米。不把u加30，不把v加16，不对八参再做平移换算。比如图像点(64,117)约映射到右-0.066445m、前0.074549m；这仅是代入计算示例，不是实测重投影误差。

## 旧Flash的处理

新记录schema=6，仍使用原256字节双槽格式、CRC和提交标志。读取旧schema2/4/5时：

- 旧center_x_px减30并限制在0～127，默认93.5迁移为63.5。
- 白线宽度和行间跳变阈值是像素差，不减30；超过128时截为128。
- 将旧八参替换为本页用户提供的128图八参，防止旧188矩阵覆盖新配置。
- 保留已有轮径、轮距、轴距、目标速度、增益及标志；schema2/4未含车长/宽时按未知零值处理。

首次加载时迁移在RAM生效。停车后进入para → save to flash保存一次，使其成为schema6；此后对标定参数的菜单修改继续优先加载，不会反复覆盖。没有有效记录时使用当前默认值。不需要全片擦除。

八参不是完成全部标定的证明；本次未更改原有发车校验、motion_plan、速度PI、元素状态机或超时逻辑。
