# V1.4 ICM20602 角速度内环

ICM20602 接主板 H2。PB3 是 SCL，PB5 是 SDA，GND 共地。供电和上拉按模块的 3.3V 接口核对，AD0 置高以使用七位地址 `0x69`。驱动初始化检查 WHO_AM_I=`0x12`，再检查关键寄存器读回。芯片寄存器和量程见 [TDK ICM20602 数据手册](https://product.tdk.com/system/files/dam/doc/product/sensor/mortion-inertial/imu/data_sheet/ds-000176-icm-20602-v1.1.pdf)。

上电把车放平并保持静止，屏幕显示 `IMU 1 CAL n/800`。程序每个 5 ms 节拍至多接收一个数据就绪样本，以三轴陀螺模长、加速度模长和编码器增量判断静止，再用 800 个合格样本的 Z 轴均值计算零偏。姿态扰动或轮子运动会清空累计，Z 轴噪声超限也会重来。理想情况下约 4 秒，实际看屏幕计数。校准前 `config_ok=false`，不能进入 READY。断线、无应答、读取超预算或数据过期会锁住 IMU 状态，READY/运行/停车中触发 `STOP_IMU`，检查接线后复位重新校准。

在 TIM6 内，原外环的 `omega_raw` 作为 `omega_target`。偏置修正后的读数和目标都使用 rad/s，左转为正。

```text
gyro_z = gyro_sign * (z_radps - bias_radps)
e = omega_target - gyro_z
I = clamp(I + yaw_ki * e * dt, -yaw_i_limit, yaw_i_limit)
omega_cmd = clamp(omega_target + yaw_kp * e + I, -yaw_output_limit, yaw_output_limit)
```

输出饱和且积分会把输出进一步推向饱和时，暂停同向积分。STOPPING 和视觉软超时减速时清积分，直接把外环目标交给原运动规划，沿原减速弧线停车。积分也会在启动/故障/非运行状态清除。

| AppParam 参数 | 默认 | 用途 |
|---|---:|---|
| `gyro_sign` | +1 | 手动左转时若屏幕测量值为负，改为 -1 |
| `yaw_kp` / `yaw_ki` | 0 / 0 | 先验证测量符号和耗时，再调 P、I。Ki 单位 1/s |
| `yaw_i_limit` / `yaw_output_limit` | 0.5 / 5 rad/s | 积分与输出的双向限幅，运动规划还会按原约束限幅 |
| `gyro_timeout_ms` | 20 ms | 距上一个有效样本的最大时长 |
| `gyro_still_radps` / `gyro_noise_radps` | 0.08 / 0.01 rad/s | 校准时陀螺模长与 Z 轴标准差门限 |
| `gyro_accel_tol_g` | 0.1 g | 校准时加速度模长偏离 1g 的容许值 |

编译默认值在 `User/config/control_tuning.h`。参数存储升级至 schema 3，每条 512 字节，Flash 槽地址和 CRC 后提交标记的顺序沿用原设计。旧记录会被拒绝，升级前应把实测车体和相机标定值转录到当前配置，验证后再保存。符号参数为 ±1，可配置，无需修改驱动。

校准期间读取加速度和三轴陀螺，完成后只读数据就绪位与 Z 轴的两个字节。软件 I²C 使用 ACK 检查和 1.8 ms 事务截止时间，应用层同时测读函数耗时，达到 2 ms 判 IMU 故障。原 4 ms 控制超时逻辑沿用。屏幕两行 `omega_target`、`omega_measured` 采用 mrad/s。屏幕 `us I… T…` 分别显示读取峰值及截至原超时检查的控制体耗时峰值，串口字段为 `imu_max_us`、`tick_max_us`。

上板先断开电机动力，确认 800 样本校准、手动左转读数为正、掉线后配置无效。再在相机和屏幕正常工作、校准和运行均覆盖的情况下看两项耗时峰值。保留现有时序验证门禁，实测完整 ISR 可用 GPIO 脉冲或调试器测量，尤其要包含快照发布、出入 ISR 和抢占开销。确认最坏情况低于 4 ms 再允许发车。若余量不足，应重新测量总线电平与时钟，可考虑隔拍采样并同步验证数据新鲜度和内环稳定性。

主机覆盖符号、积分限幅、输出饱和、NaN、校准门禁和运行掉线故障。WCH 目标构建通过。I²C 通信、完整 ISR 耗时、实际安装符号和实车内环调参仍待上板。
