# V1.1 新版视觉实现说明

日期：2026-11-01。依据用户提供的“视觉大纲”图片，更新白线宽25mm、平行赛道间距20cm、188×120前置灰度图的视觉方案。旧版两圈、分叉两支等任务要求继续保留，截图没有说明取消它们。

## 实际代码变化

`vision_boundary.c` 新增 Otsu 自动阈值、底部附近种子搜索、连通域提取、边界追踪、画面截断区间和折点记录。`vision_line.c` 使用同一个连通域生成候选路径，`path_control.c` 使用选中出口/折点给方向与距离，`debug_view.c` 使用当前帧 Otsu 阈值显示二值图。

处理链路：灰度帧 → 全帧256级直方图/Otsu → 底部最近白色道路连通域 → Moore八邻域边界追踪 → 截断区间及折点 → 连续候选路径 → 原有多帧元素状态机 → 目标方向角/像素距离 → 差速约束与侧速度PI。

没有生成第二张灰度图或逆透视图。连通域用每像素1bit保存，188×120共2820字节。直方图与连通域种子栈分时复用同一个512字节联合体。图像仍借用DVP完整帧，处理结束才归还。

## 截断与折点的具体定义

截断是**所选道路连通域与画面周边相交的连续白区间**，不是白黑转换的像素点数。周边按下→左→上→右循环遍历，角点只出现一次，跨起始点的区间也只记一次。宽度小于2像素忽略。最多8个区间，超容量拒绝作为有效帧。

从画面底部向上最多9行寻找离中心最近的白像素，再做四连通扫描线扩展。因此独立平行白线不会混入本车道路；如果道路被遮挡而断开，远端不会被凭空连接。种子栈最多128项，溢出拒绝帧。

边界追踪采用八邻域 Moore 邻域搜索；以“起点和首条边再次出现”判定闭合，不只看回到一个像素。最多遍历两倍图像像素数，不能闭合则拒绝帧。每8步用前后方向变化提取折点，最多保留16个，保留位置和画面左右半区标记。

当前追踪所选连通域的一条外轮廓，行扫描继续保留多白段用于分支选择；**尚未逐一枚举环岛内部所有封闭孔洞轮廓**。折点的左右标签表示画面半区，不等于严格意义的“车道左边界/右边界身份”。这是当前实现与截图文字中理想边界模型的区别，不能将其当成已经完成通用拓扑重建。

## 元素判据与控制

| 证据 | 当前处理 |
|---|---|
| 两个截断区间 | 普通道路候选；没有足够有效路径仍拒绝 |
| 两个区间、存在近处折点 | 普通弯道选目标时参考选中侧折点 |
| 四个区间且覆盖下/左/上/右四边 | 十字候选，目标强制选上边出口，接原确认/通过/清出状态 |
| 三个区间 | 分叉候选，接原选支和两圈记录 |
| 四个区间且至少三个中点位于同一画面半区 | 环岛候选，结合现场路线身份接原环岛状态机 |
| 低对比度、无法闭合、容量溢出 | 不发布有效运动目标，继续由原超时策略停车 |

截断个数只是候选证据，十字和分叉仍用确认时间及通过状态；Y/环岛仍依赖经验证的现场事件顺序区分。环岛没有改成“第二次四截断就直接出环”，保留进入、内部跟随、最短进度、出口重遇、清出状态。现有未配置路线遇到分叉会停车。

对于没有上边出口的90°弯，候选路径可以选择左/右边出口，方向不再仅由远端行中线的平均数决定。连通路径在至少3个采样行有效且有两个出口时允许最低60的置信度，以适应只在近处可见的直角弯。

## 控制接口

`MotionRequest` 新增：

- `direction_rad`：从画面正前方指向目标点的方向角，右为正。
- `distance_px`：底部参考点到目标点的像素欧氏距离。

`omega_raw` 保持车体左转为正，所以方向PD输出取负号。右侧目标导致左轮快、右轮慢。目标一般取候选路径对应的非底部出口；十字选上边出口。普通弯道的近处同侧折点会参与目标点平均，提供较近的转向参考。

`distance_px` 当前用于观察/接口传递，未伪装成米，也没有直接代入轮端距离控制。后轴清出仍使用此前实测行距和轮周里程。尚未实现截图描述的完整“第一折点远近→下一折点”几何策略，而是有界的近折点目标修正。

原 `threshold` 参数保留兼容旧参数记录，但识别和静态二值图显示使用每帧 Otsu 阈值。直方图类间方差不足的低对比度图像拒绝；一旦输出目标角取代归一化横向误差，原PD增益也需要重新标定。

## 标定、资源与验证

`CAL_VISION_V2_VALIDATED` 默认0。它与原标定条件一起决定是否允许准备，旧Flash记录不能绕过这个编译期检查。确认完整帧、图像朝向、元素选择、方向增益、最坏处理时间后才手动置1。硬件尺寸及机械方向等原标定仍必需。

主机测试直接调用生产代码，包含亮度改变后的直角弯、十字对面目标、三出口分叉、无关平行线过滤、相连白段超容量、低动态范围及原有控制/参数/状态回归。主机案例不代表真实镜头畸变、反光、运动模糊和环岛拓扑已经验证。

构建方法同README，当前工具链位置为MounRiver Studio3。新版固件和源文件校验记录保存在 `release/v1.1`；旧 `release/v1.0` 保留为历史快照。当前32KiB RAM配置接近容量上限，已预留2KiB栈，但运行栈峰值和处理延迟仍需要实物测量。
