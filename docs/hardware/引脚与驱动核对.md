## 1. 电机：右侧两个信号的次序与左侧不同

以下对应关系成立的前提是主板 H3 和驱动板 CN5 按**同脚号 1→1、2→2、3→3、4→4**接线。两个独立工程本身不能证明实物线束已经这样接好。

| 用途 | MCU 物理脚 / 端口 | 主板缓冲链路 | H3 | 驱动板 CN5 | 驱动芯片 |
|---|---|---|---|---|---|
| 左 PWM | 40 / PE9 | LPWM_1_E9 → U4.2 → U4.3 → L1 | 1 | 1 EN_L | U1.14 EN |
| 左方向 | 42 / PE11 | LPWM_2_E11 → U4.5 → U4.6 → L2 | 2 | 2 PH_L | U1.15 PH |
| 右方向 | 44 / PE13 | RPWM_1_E13 → U4.12 → U4.11 → R1 | 3 | 3 PH_R | U2.15 PH |
| 右 PWM | 45 / PE14 | RPWM_2_E14 → U4.9 → U4.8 → R2 | 4 | 4 EN_R | U2.14 EN |

U4 是 74HC125，同相缓冲，四个 OE 接地。它没有把 EN 与 PH 自动互换。主板网络名里带 PWM，也不代表接到驱动板后一定应该输出 PWM。

代码使用 **TIM1 全重映射 MAP3，CH1/PE9 和 CH4/PE14**，共同频率 20 kHz；PE11、PE13 作为 GPIO。不能把右 PWM 写成 PE13。对应源码是 `User/board/board_config.h` 和 `User/board/board_port.c`。

## 2. DRV8701E 的实际控制边界

左右分别是一颗 DRV8701E 和一组外置全桥 MOSFET，输出 CN3 的 M+_L/M-_L、CN4 的 M+_R/M-_R。参考车同侧前后轮用齿轮联动，因此软件只输出两路侧速度。

| 条件 | 电气动作 | 本工程处理 |
|---|---|---|
| nSLEEP 高、EN=0 | 低侧刹车 | 占空比 0；正常停机和故障都回到这里 |
| nSLEEP 高、EN=1、PH=0 | SH2→SH1 驱动 | 方向之一 |
| nSLEEP 高、EN=1、PH=1 | SH1→SH2 驱动 | 另一个方向 |
| nSLEEP 低 | 全桥高阻休眠 | 这块板没有给 MCU 提供可直接控制的休眠接口 |

依据：[TI DRV8701 数据手册，7.3.1 PH/EN 控制表](https://www.ti.com/lit/ds/symlink/drv8701.pdf)。EN=0 不能写成“自由滑行”。

U1/U2 的 13 脚同接 SLEEP；该网络经 R4 接 VM，并有 D2 到地，是板上硬件网络。SP/SN 即 20/21 脚接地；SO、SNSOUT、nFAULT 即 9/10/11 脚没有接出网络。故本版没有可供 MCU 使用的电机电流采样或驱动故障输入，也没有软件电流闭环。占空比限幅不能替代电流检测。

`BOARD_LEFT_PH_FORWARD=1`、`BOARD_RIGHT_PH_FORWARD=0` **仍是待实物校准的初始方向值**。电气方向不等于车轮向前：电机引线、镜像安装、主动齿轮都会改变对应关系。`CAL_MASK` 的方向位默认不置位，防止将这个初值当成已确认的机械方向。

## 3. 两侧编码器

| 接口 | 1 | 2 | 3 | 4 | 定时器 |
|---|---|---|---|---|---|
| 主板 CN5 左编码器 | 3.3V | PA0 / L_EN_1_A0 | PA1 / L_EN_2_A1 | GND | TIM2 MAP0 CH1/CH2 |
| 主板 CN6 右编码器 | 3.3V | PD12 / R_EN_1_D12 | PD13 / R_EN_2_D13 | GND | TIM4 MAP1 CH1/CH2 |

注意“主板 CN5”是编码器接口，“驱动板 CN5”是电机控制接口，两者不是同一插座。编码器输入按 3.3V 系统设计；购买模块后还要核对实际输出电平。逐飞库正交初始化用 TI2 模式，不能未经实测直接套 PPR×4。

## 5. 屏幕、按键、调试、IMU

| 用途 | MCU / 配置 | 状态 |
|---|---|---|
| TFT 时钟 / 数据 | PB13 / PB15，SPI2 MAP0 | 网络已核对；本版按 TFT180 驱动，具体屏型号仍需核实 |
| TFT RESET / DC / CS / BL | PB7 / PD7 / PD4 / PD0 | 已核对 |
| 按键译码 A2/A1/A0 | PB14 / PB12 / PD8，U15 74HC148 | 低有效优先编码，不是三个独立按键 |
| UART3 TX/RX | PB10 / PB11，115200 | H4 接出；仅调试日志 |
| SWDIO / SWCLK | PA13 / PA14 | 保留下载调试 |
| IMU H2 SCL/SDA | PB3 / PB5 | 接口已核对，模块型号和驱动未定；V1.0 未启用 IMU |
| 控制节拍 / 时间基准 | TIM6 5ms / TIM7 1MHz | 内部资源，无外接引脚 |

按 A2/A1/A0 顺序读值：7 无按键，1 中，2 右，4 上，5 下，6 左，3 KEY1，0 KEY2。多键同时按下时有硬件优先级，代码没有把它伪装为独立按键位图。

## 6. 已确认与仍需实测的分界

已经确认：芯片引脚、PCB 信号连接、两路 PH/EN、缓冲器、编码器接口和外设资源分配。

仍需实测：实物线束脚号、车轮前进极性、编码器正负号与轮端一圈计数、轮径/轮距/轴距、相机完整帧与视野标定、四轮擦地后的等效轮距、赛道拓扑。它们不会从原理图里自动得到。代码保留未标定禁止发车的检查。
