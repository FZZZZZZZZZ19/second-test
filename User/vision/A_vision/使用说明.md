# 队友视觉模块

主循环通过 `team_vision_step(frame, params, session, out, preview)` 使用本模块。帧必须是 188×120，行距至少 188。模块直接读取相机快照。坐标转换读取当前 AppParam 中的八个标定系数。可选的 preview 返回同一帧三个原图像素点，供屏幕标记。

`team_vision_reset()` 由集成层在会话切换和预览后调用。底层 `team_vision_points()` 成功时返回近、中、远像素点与元素阶段，失败时丢弃本帧几何。阈值补偿、白黑段宽度、统计范围、单边中线偏移和预瞄距离集中在 vision_all.c 顶部。LR 当前为 0，对应左侧策略。
